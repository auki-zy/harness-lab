# 任务：wc-cli（固定任务，两个条件各跑一次）

写一个 Node 脚本 `wc.mjs`，放在**当前工作目录**里，用法：

```bash
node wc.mjs <file>
```

输出一行 JSON（不要别的输出）。下例就是本任务 `input.txt` 应该得到的结果：

```json
{ "lines": 5, "words": 10, "chars": 58 }
```

口径（必须完全按这个来）：

- `lines` = 文件按 `\n` 切分后的行数；文件以 `\n` 结尾时，末尾那个空段不计。
- `words` = 去掉首尾空白后按连续空白切分的词数；文件为空时是 `0`。
- `chars` = 文件字符数（不是字节数）。
- 文件不存在 → 打印错误到 stderr 并以退出码 1 结束。
- 只允许用 Node 自带能力，**不允许安装任何依赖**。
- 只交付 `wc.mjs` 这一个文件。

跑测用的输入文件是同目录的 `input.txt`。
