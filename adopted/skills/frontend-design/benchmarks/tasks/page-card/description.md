# 任务：page-card（视觉 A/B 固定任务）

产出一个**单文件** `page-card.html`（内联 CSS，无框架、无 JS、无外部资源）。

内容与结构：
- 页头：标题「团队成员」+ 一句副标题；
- 工具区：一个搜索输入框（仅样式，不需要功能）；
- 列表：3 张成员卡片，每张含：头像占位（可用首字母色块）、姓名、职位、邮箱、一个状态标签（在职 / 休假 / 远程 各一）；
- 空态：页面底部给一个"暂无更多成员"的示例区块；
- 中文文案，文案自拟但需真实（不要 lorem ipsum）。

约束：
- 窄屏（≤480px）下卡片改为单列且不横向溢出；
- 一个主行动强调即可（例如"邀请成员"按钮）；
- 可访问性基本面：语义标签、输入有 label、状态标签不只用颜色表达。

评审方式（人工）：两版并排打开，按 `benchmarks/SCORING.md` 打分。
