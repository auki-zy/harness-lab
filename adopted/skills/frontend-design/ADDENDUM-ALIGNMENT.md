# 补充：对齐纪律清单（非官方内容）

> ⚠️ 本文件**不属于**官方 frontend-design 技能（官方原文见同目录 `SKILL.md`，Apache-2.0）。
> 它是我们在实测中得到的教训：官方版把力气花在"审美主张"上，**结构性对齐**仍需自查——必要时把本清单当附加检查项使用，不要改写官方正文。

## 为什么有这份补充

在 `benchmarks/tasks/page-card` 的对照里，**不加载能力那一版（A）能看出结构对齐上的短板**（等宽等高、基线、底部贴齐这类）。这份清单就是把这类"看一眼就知道不对、但很容易漏"的点固化成自查项——它是**结构自查**，不是人评结论；审美主张以官方 `SKILL.md` 为准。

## 对齐自查（提交前逐条过）

- [ ] 卡片/列表项**等宽等高**；多列时**基线一致**
- [ ] 文本**左边界统一**；列表左右边界一致
- [ ] 图标与相邻文本**垂直居中**（用 flex 居中，别用 padding 猜）
- [ ] 卡片内"底部动作/次要信息"**贴底**（`margin-top:auto`），避免高度不一时参差
- [ ] 间距取同一组倍数（如 4 的倍数），**数学对齐 ≠ 视觉对齐**
- [ ] 响应式：窄屏单列、无横向溢出（`min-width:0` + `overflow-wrap`）

## 关系

- 审美主张 → 官方 `SKILL.md`；
- 结构对齐 → 本清单（可作为 review checklist，或将来并入 `ARCHITECTURE.md` 工程约定里的验证项）。
