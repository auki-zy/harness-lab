交付完成：`ui-audit.mjs`（仅此一个文件，纯 Node 内置能力，无依赖）。

用法：`node ui-audit.mjs <json文件路径>`

实现要点：
- 对比度用标准 WCAG 相对亮度公式（sRGB 通道线性化 → `0.2126R+0.7152G+0.0722B`，比值 `(L亮+0.05)/(L暗+0.05)`），`< 4.5` 记为违规。
- 图标用 `for...of` 按码点遍历（正确处理代理对），任一码点 `>= 0x1F000` 即违规。
- 所有输出先算完再一次性写出，保证失败路径 stdout 绝对为空；读文件/JSON 解析/结构异常一律 `exit 1`。

实测结果：
