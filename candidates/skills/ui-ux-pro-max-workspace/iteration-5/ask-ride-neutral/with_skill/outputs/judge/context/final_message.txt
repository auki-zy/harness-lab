**表单校验**（跑了 25 个用例）能逐条说清错在哪：缺 `@`、多个 `@`、`@` 前没用户名、`@` 后没域名、域名没后缀、后缀太短/含数字、域名有连续点号或首尾连字符、用户名点号位置不对、含空格……提交失败会把焦点送回输入框，提示用 `role="alert"` 播报。

**两件事需要你知道：**

1. **表单目前不发任何请求。** 纯前端校验 + 本地成功提示。接入后端的位置我在 JS 里用 `// === 接入后端的位置 ===` 标好了，换成 `fetch` 即可。所以现在那个"订阅成功"只是演示。
2. **主题开关是三态**（跟随系统 → 浅色 → 深色 → 循环），不是二态。你说"默认跟着系统走"，二态开关一旦点过就回不到跟随系统了，所以留了三态；按钮上的文字会跟着变（自动/浅色/深色）。如果你想要纯二态，我改掉。
